Lume 0.2.5
==========

Windows 11 的快速启动器：Alt+Space 唤出，输入即搜应用和文件，回车启动。
空查询只推荐最近最常用的条目；还没有使用记录时只显示输入框。

系统要求
--------
- Windows 11 22H2（build 22621）或更高，x64
- 免安装、免管理员、无需运行库（单 exe）

推荐安装方式
------------
双击 Install.cmd。
它会把 Lume.exe 复制到 %LOCALAPPDATA%\Programs\Lume 并从那里启动，
不会出现黑色控制台窗口，托盘图标也能正常创建。
之后从该目录（%LOCALAPPDATA%\Programs\Lume）启动 Lume.exe 即可；安装脚本不会创建桌面或开始菜单快捷方式。

如果直接双击 Lume.exe 后托盘没有图标
------------------------------------
说明 Lume.exe 所在目录带有 Low Integrity（低完整性）标签
（例如 DSH/受限工作区），Windows 的 UIPI 会阻止程序创建托盘图标。
解决办法（任选其一）：
1. 双击 Install.cmd（推荐，自动复制到普通用户目录并启动）；
2. 把 Lume.exe 复制到桌面或 C:\Apps\Lume 再双击；
3. 以管理员身份运行（不推荐，仅临时验证）。
日志里会出现“当前进程是低完整性 (Low IL)”提示。

快速开始
--------
1. 启动 Lume.exe，程序常驻托盘（不会出现黑色控制台窗口）。
2. 按 Alt+Space 唤出/隐藏搜索框。
3. 空查询显示最近最常用的应用/文件（没有记录时只有输入框）；
   输入应用名或文件名开始搜索：
   - 鼠标：指针移到结果上会高亮，单击即启动/打开（Shift+单击=定位，Ctrl+单击=管理员）
   - Enter：启动/打开
   - Shift+Enter：在资源管理器中定位
   - Ctrl+Enter：以管理员身份运行（应用）
   - Esc：清空/隐藏
4. 右键托盘图标：显示、开机自启、设置、退出。
5. 退出请走托盘菜单的“退出”。

设置（四页）
------------
常规页：主题（跟随系统/深色/浅色）、强调色、热键、开机自动启动。
索引页：
- 索引大小上限（MB，64–262144，默认 512）；
- 索引文件目录：只读下拉框，可切换当前目录 / 默认目录 / 最近用过的 5 个目录
  （不存在的目录不会出现在列表里），下面有「修改目录 / 打开索引目录 / 恢复默认」；
- 索引状态：快照大小、条目数、上限占用率、上次重建耗时（点「刷新状态」刷新）；
- 文件索引根目录增删；
- 清除索引（只删快照+清空，不重建）/ 重建索引（立即后台重建并写回快照）。
筛选页：搜索框下方那排筛选组的启用开关、组的增删改与恢复默认（详见下一节）。
底部按钮：应用（生效但不关窗）、保存（生效并关窗）、取消（丢弃修改）。

文件搜索来源（索引页最上面一行）
--------------------------------
- Lume 本地索引（默认）：只索引「文件索引目录」里列出的根目录，快照写 files.idx。
- Everything 全盘索引：改用本机 Everything（1.4/1.5，需要它正在后台运行）的全盘索引。
  切过去后本地索引会停止，并删除 files.idx 释放空间；索引大小、索引目录、根目录这些
  本地索引专用设置会变为不可用。
- 如果切过去时 Everything 没在运行：不会删快照，搜索结果只出应用；等 Everything 起来后
  再点一次「刷新状态」或重新应用即可，快照那时才会被删除。
- 切回「Lume 本地索引」会重新建立索引（512 MB 预算下约 20 秒），期间文件结果暂时为空。
- 命令行可以临时覆盖：Lume.exe --file-search=everything；自检用 Lume.exe --everything-check。

筛选组（搜索框下面那一排）
--------------------------
- 默认有：全部 / 应用程序 / 图片 / 文档 / 音频 / 视频 / 压缩包，点一下即可只看这一类。
- 键盘：Tab 下一个、Shift+Tab 上一个、Ctrl+1..9 直接跳到第 N 个（1 = 全部）。
- 鼠标：这排芯片可以直接点；上面的结果行也是「指针移上去高亮、单击启动」。
- 一组 = 一组扩展名 + 三个开关（包含应用索引 / 包含文件夹 / 包含无扩展名文件）；
  「全部」固定在最前，不能改名也不能删除。
- 设置 → 筛选：新建、删除、上移、下移、改名、改扩展名规则（空格/逗号/分号分隔，
  写 *.PNG 也会被归一成 png）、三个开关、以及一键「恢复默认」。
  重名、没有任何规则的组、超过 12 个组会在点「应用/保存」时被拦下并提示原因。
- 选择会记住：下次唤出仍停在上次那一组；不想要这排芯片就在筛选页关掉
  「在搜索框下方显示筛选组」。
- 命令行：Lume.exe --filter=图片（或 --filter=3 / --filter=all / --filter=off），
  Lume.exe --list-filters 可以打印当前生效的组与规则。

首次启动
--------
- 文件索引默认根目录为桌面/文档/下载；可在「设置 → 索引」里添加，例如 C:\、D:\。
- 索引大小默认 512MB，可在设置里改（64–262144 MB）；索引文件位置也可改。
- 启动会先读上次快照，同时在后台重建；首次或点「重建索引」会写入快照。
- 索引数据默认在 %LOCALAPPDATA%\Lume（可在设置里改目录），
  设置在 %APPDATA%\Lume，使用记录在 %APPDATA%\Lume\usage.conf（退出时写入），
  日志在 Lume.exe 同目录的 Lume.log（该目录不可写时退回 %LOCALAPPDATA%\Lume\logs）。
- 日志分四级，默认只记正常使用的轨迹；排查问题时把「设置 → 常规 → 详细日志（开发排查用）」
  勾上（或命令行加 --debug），会额外记录每次按键、悬停与 Everything 往返。日志超过 2MB
  会在下次启动时轮转为 Lume.log.1。
- 旧的 eTools 配置会自动迁移到 Lume。

关于页
------
- 显示版本、运行环境（Windows 版本 / x64 / DPI）、当前热键、文件搜索来源与 Everything 状态，
  以及 settings.conf、usage.conf、日志目录、索引目录四个路径。
- 「复制版本信息」把整段信息复制到剪贴板，回报问题时直接粘贴即可。

卸载
----
- 托盘右键“退出”；
- 删除 Lume.exe 和 %APPDATA%\Lume、%LOCALAPPDATA%\Lume、%LOCALAPPDATA%\Programs\Lume；
- 如开启过开机自启，可在设置里关闭，或删除 HKCU\Software\Microsoft\Windows\CurrentVersion\Run 下的 Lume。

说明
----
- 本程序未签名，Windows SmartScreen 可能提示“未知发布者”，选择“仍要运行”即可。
- 托盘图标是蓝底白色镜头；如果没看到，请检查任务栏溢出区（^）并把它拖到常驻区。
- 命令行模式（--version、--list-apps 等）会附加当前终端；双击运行不会弹控制台。
- 版本：Lume 0.2.5。
